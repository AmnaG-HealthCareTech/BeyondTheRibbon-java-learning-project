# 🎀 Beyond the Ribbon

**A breast health education interface built with Java Swing.**

## About the Project

Beyond the Ribbon is a learning project exploring how technology and thoughtful design can make breast health education more approachable.

The project features a clean, welcoming graphical interface designed to help users explore breast health information and trusted educational resources.

## Features

- Custom graphical user interface
- Soft pink and burgundy colour palette
- Rounded panels and content cards
- Introductory breast health education content

## Technologies Used

- Java
- Java Swing
- AWT
- Visual Studio Code

## Current Progress

This project is a work in progress. I'm learning Java GUI development and refining the interface step by step.

## Future Goals

- Add interactive resource cards
- Improve navigation
- Expand educational content
- Continue refining the user experience

## Disclaimer

This is an educational development project, not a medical diagnostic tool. The project is still under development.
